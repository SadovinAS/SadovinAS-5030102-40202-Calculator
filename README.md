# Калькулятор
# Садовин Александр Сергеевич 5030102/40202

Калькулятор поддерживает стандартные бинарные операции(+ - * /), унарные(+ -) и круглые скобки.
Поддерживает добавление функций и операций.
Функции имеют формат f(x, y, ...).
Имеется поддержка постфиксных и префиксных унарных и бинарных операций.
Все операции вычисляются в типе double.
В проекте приведены 4 библиотеки с операциями и функциями.
Названия функций должны начинаться с буквы, но могут продолжаться цифрами.

Программа запускается через файл CMakeTarget.exe.
В поле ввода необходимо ввести выражение.
Программа продолжит работать в цикле, пока не будет введена пустая строка.
